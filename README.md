# Prep

A multi-module Java Gradle project for practicing coding, design patterns, and Low-Level Design (LLD).

## Project Structure

```
prep
|
├── design-patterns
│   ├── strategy
│   ├── factory
│   ├── observer
│
└── lld
    ├── parking-lot
    ├── splitwise
    ├── bookmyshow
```

## Running the Project

You can run Gradle tasks using the Gradle wrapper from the root of the project:

- **List all subprojects:**
  ```bash
  ./gradlew projects
  ```

- **Build all subprojects:**
  ```bash
  ./gradlew build
  ```

- **Run tests:**
  ```bash
  ./gradlew test
  ```
